# Формализация соционики

**Язык:** Русский · [English](README.en.md)

Открытый исследовательский корпус: исходные определения и таблицы, исторические отчёты с вычислительными пакетами, рабочие главы формализации и воспроизводимые проверки. Публикация исследования означает доступность его текста, а не подтверждение каждого утверждения.

## Навигация

- [`HANDOFF.md`](HANDOFF.md) — исследовательский контекст, математическая постановка, проверенное и открытые задачи для следующего агента.
- `sources/primary/` — 26 исходных Markdown-документов в неизменённой копии. Черновые статьи здесь являются источниками формул, а не автоматически принятыми теоремами.
- `sources/context/gpt-output.md` — предоставленный аналитический текст; его утверждения требуют самостоятельной проверки.
- `agent-researches/` — исторические отчёты, архивы и вычислительные данные из `research-harness`. Некоторые результаты уточняют или исправляют прежние.
- `formalization/aspect-patterns.md` — рабочая глава об аспектных паттернах и действии на парных разбиениях.
- `formalization/equivariant-8T9/` — отдельный прототип алгебры функций на 8T9 с таблицей-источником и тестами.
- `audits/`, `tools/`, `tests/` — журнал расхождений, проверяющие программы и регрессионные тесты.
- `provenance/import-manifest.json` — SHA-256 каждого импортированного файла и его исходная коллекция.

## Проверка

Из корня репозитория:

```bash
python -m unittest discover -s tests -v
python tools/verify_aspect_patterns.py
python -m unittest discover -s formalization/equivariant-8T9 -v
```

Некоторые проверки аудита принимают локальный путь к авторскому источнику; пример команды приведён в `audits/dichotomy-definitions-and-corrections.md`. Точные границы каждой проверки следует читать в соответствующем отчёте. Исходные тексты и архивы не редактируются для получения «проходящих» тестов.

## Статусы

Для утверждений различаются определение, математическое следствие из названных аксиом, проверка конечной таблицы, реконструкция авторского замысла и гипотеза. Согласие формулы с 16 заданными моделями устанавливает распознавание в выбранном семействе; единственность восстановления моделей среди всех биекций требует отдельного исследования.

Включён исторический повреждённый архив `agent-researches/2026-09-07-tencer-minaev-audit.zip`: он не открывается как ZIP. Рядом находится версия `-FIXED.zip`; статус и их соотношение следует проверять по содержимому, не считать оригинал исправленным.

Монография из соседнего старого проекта как самостоятельный текст сюда не импортирована. Отдельные исторические вычислительные пакеты могут содержать копии использованных исходных черновиков — это зафиксированные входные данные пакетов. Лицензия на повторное использование пока не выбрана; публичный доступ сам по себе не задаёт лицензии.
