# Базовая конструктивная формализация

Статус: рабочая редакция для согласования с автором. Эта папка содержит последовательное изложение; исторические отчёты и первичные тексты остаются источниками, а не заменяют главы.

## Порядок построения

1. Матрицы Адамара, XNOR и соответствия Чурюмова.
2. Формулы инвариантов по авторской теории поколений.
3. Комбинирование аспектных составляющих с аспектными и функциональных с функциональными; совместимость с XNOR столбцов Социона.
4. Однозначное построение моделей А из формул.
5. Композиция построенных перестановок и реализация 8T9.

Под «эквивариантностью формул признакам» в этой работе понимается заявленная автором согласованность операций над формулами с операцией над соответствующими признаками. Точное равенство согласованности записывается для каждого установленного вида формул. Отдельное действие перестановочной группы на алгебре формул не является предпосылкой построения.

## Согласованная нотация

- XNOR — $\odot$; зависимость признаков записывается как произведение всех участвующих составляющих, равное нейтральному элементу $1$.
- Вертность — $\operatorname{vert}(t)$; остальные признаки — $\operatorname{dichT}_m(t)$ по индексу столбца.
- Отображение аспекта — $t(i)$, множества аспектов — $t(S)$.
- Диады и тетрады записываются явно; дополнительные обозначения $Q$, $K$ не вводятся.
- Для принадлежности одной диаде требуется одновременное совпадение по каждой из трёх дихотомий. Это условие отличается от алгебраической зависимости трёх столбцов.
- Формат математики: `$...$` и `$$...$$`, совместимый с Obsidian.

## Статусы утверждений

- **Исходное правило**: принятое авторское соответствие или условие построения.
- **Доказанное следствие**: утверждение с указанными предпосылками и доказательством.
- **Конечная проверка**: результат исполняемой проверки с названными данными и областью перебора.
- **Открытый вопрос**: ещё не установленное правило или утверждение.

Добавленные ассистентом координаты и способы записи обозначаются как формальная запись или реконструкция, а не как историческое авторское определение.

```bash
python -m unittest discover -s tests -p "test_base_*.py" -v
```

Эти проверки сравнивают построенные матрицы с первичным источником, проверяют XNOR строк и столбцов, соответствие опорной модели, полный каталог главы 2 и примеры операции над поточечными формулами. Они не объявляют проверенной общую алгебру всех поколений или конструктивную теорему восстановления.

Следующее содержательное звено: предложить механизм комбинирования формул на противоположных нальностях, начиная с беспечности и уступчивости. Затем оформить теорему построения моделей. Подтверждённое ранее сессионное вычисление единственности требует долговечной реализации и доказательства; оно не подменяет ещё не написанную главу.
