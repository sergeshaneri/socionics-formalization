# 4. Построение модели А по базису Юнга

## 4.1. Четыре исходных полюса

Для построения задаются вертность, нальность, интуиция и логика типа. Их значения кратко обозначим

$$
v=\operatorname{vert}(t),\qquad n=\operatorname{nal}(t),\qquad
u=\partial_4^{T}(t),\qquad l=\partial_8^{T}(t).
$$

Это четыре значения в $\mathbb B=\{1,0\}$. Положительные полюса: экстраверсия, иррациональность, интуиция и логика. Поэтому $n=1$ означает иррациональность, $n=0$ — рациональность. Буквы $v,n,u,l$ используются только для короткой записи заданных значений; новые признаки ими не вводятся.

Исходными данными являются таблицы признаков аспектов и функций из [главы 1](01-hadamard-and-correspondence.md) и четыре структурных правила из [главы 2](02-generations-and-invariant-formulas.md). Готовая таблица моделей А в построении не используется.

## 4.2. Полная система условий

Ищется биекция $t:I\to F$, одновременно удовлетворяющая следующим правилам:

$$
\begin{aligned}
\partial_2^{I}(i)\odot\partial_2^{F}(t(i))&=v &&\text{для всех }i\in I,\\
\partial_7^{I}(i)\odot\partial_7^{F}(t(i))&=n &&\text{для всех }i\in I,\\
\partial_4^{I}(i)\odot\partial_4^{F}(t(i))&=u &&\text{при }\partial_7^{I}(i)=1,\\
\partial_4^{I}(i)\odot\partial_4^{F}(t(i))&=l &&\text{при }\partial_7^{I}(i)=0.
\end{aligned}
$$

Первые два условия действуют на всех аспектах. Интуиция задаёт размещение интуитивных и сенсорных диад; логика — логических и этических диад. Условия каждого из двух последних правил сохраняются для обеих диад своей нальности.

Вертность и нальность сохраняют полюс при значении типа 1 и меняют его при значении 0. Столбец $\partial_4^{F}$ различает сильные функции $\{1,2,7,8\}$ и слабые $\{3,4,5,6\}$. На иррациональных аспектах $\partial_4^{I}=1$ для ЧИ, БИ и 0 для БС, ЧС; на рациональных — 1 для ЧЛ, БЛ и 0 для ЧЭ, БЭ.

Таким образом, при $u=1$ интуитивные аспекты размещаются в сильных функциях, сенсорные — в слабых; при $u=0$ назначения меняются. При $l=1$ логические аспекты размещаются в сильных функциях, этические — в слабых; при $l=0$ назначения меняются.

## 4.3. Определение позиции каждого аспекта

Каждая функциональная позиция однозначно определяется тройкой: вертность, нальность, сила.

| Позиция $f$ | $\partial_2^{F}(f)$ — вертность | $\partial_7^{F}(f)$ — нальность | $\partial_4^{F}(f)$ — сила |
|---|---|---|---|
| 1 | 1 | 1 | 1 |
| 2 | 0 | 0 | 1 |
| 3 | 1 | 1 | 0 |
| 4 | 0 | 0 | 0 |
| 5 | 0 | 1 | 0 |
| 6 | 1 | 0 | 0 |
| 7 | 0 | 1 | 1 |
| 8 | 1 | 0 | 1 |

Таблица содержит все восемь троек из $\mathbb B^3$, каждую ровно один раз. Для заданного аспекта $i$ требуемая тройка вычисляется так:

$$
\partial_2^{F}(t(i))=\partial_2^{I}(i)\odot v,
$$
$$
\partial_7^{F}(t(i))=\partial_7^{I}(i)\odot n,
$$
$$
\partial_4^{F}(t(i))=
\begin{cases}
\partial_4^{I}(i)\odot u,&\partial_7^{I}(i)=1,\\
\partial_4^{I}(i)\odot l,&\partial_7^{I}(i)=0.
\end{cases}
$$

Полученную тройку нужно найти в функциональной таблице. Номер её строки по позиции $f$ и есть $t(i)$. Повторение для восьми аспектов строит всю модель.

Для вычислений аспектные тройки имеют вид:

| Аспект $i$ | $\partial_2^{I}(i)$ | $\partial_7^{I}(i)$ | $\partial_4^{I}(i)$ |
|---|---|---|---|
| ЧИ | 1 | 1 | 1 |
| БС | 0 | 1 | 0 |
| ЧЭ | 1 | 0 | 0 |
| БЛ | 0 | 0 | 1 |
| ЧЛ | 1 | 0 | 1 |
| БЭ | 0 | 0 | 0 |
| ЧС | 1 | 1 | 0 |
| БИ | 0 | 1 | 1 |

## 4.4. Существование и единственность

**Утверждение J-01.** Для каждого сочетания $(v,n,u,l)\in\mathbb B^4$ существует ровно одна биекция $t:I\to F$, удовлетворяющая четырём полным правилам §4.2. Построение §4.3 задаёт эту биекцию.

**Единственность позиции.** Для каждого аспекта правила определяют одну тройку функциональных значений. Каждой тройке соответствует ровно одна функция. Поэтому любое решение обязано совпадать с построенным отображением на каждом аспекте.

**Биективность построенного отображения.** Аспектная таблица тоже содержит все восемь троек, каждую ровно один раз. Два аспекта различной нальности получают разную функциональную нальность: XNOR с одним и тем же $n$ сохраняет различие. Для двух аспектов одной нальности сила преобразуется с одним и тем же значением $u$ или $l$. XNOR с фиксированным значением сохраняет различие и вертности, и силы. Поэтому различные аспектные тройки получают различные функциональные тройки. Восемь аспектов занимают восемь различных функций; следовательно, $t(I)=F$.

**Выполнение условий.** XNOR с фиксированным полюсом является обратной самому себе операцией. Подстановка трёх вычисленных функциональных значений в §4.2 возвращает $v,n,u,l$. Все четыре полных правила выполнены.

**Различимость моделей.** Значения $v$ и $n$ восстанавливаются из сравнений аспектных и функциональных полюсов на любом аспекте; $u$ — на любом иррациональном аспекте, $l$ — на любом рациональном. Поэтому разные исходные четвёрки дают разные модели.

Утверждение относится ко всем биекциям $I\to F$, а не только к исходной таблице моделей. Оно использует согласованные таблицы аспектных и функциональных признаков и полные структурные правила; матрица Адамара без этих правил сама по себе модели не определяет.

## 4.5. Пример: ЭИЭ

Для ЭИЭ задано $(v,n,u,l)=(1,0,1,0)$: экстраверсия, рациональность, интуиция, этика. Вычисление требуемых функциональных значений:

| Аспект | Вертность функции | Нальность функции | Сила функции | Позиция |
|---|---|---|---|---|
| ЧИ | 1 | 0 | 1 | 8 |
| БС | 0 | 0 | 0 | 4 |
| ЧЭ | 1 | 1 | 1 | 1 |
| БЛ | 0 | 1 | 0 | 5 |
| ЧЛ | 1 | 1 | 0 | 3 |
| БЭ | 0 | 1 | 1 | 7 |
| ЧС | 1 | 0 | 0 | 6 |
| БИ | 0 | 0 | 1 | 2 |

Например, ЧЭ имеет аспектную тройку $(1,0,0)$. Вертность сохраняется, нальность меняется, а сила определяется логикой/этикой, поскольку аспект рациональный. При $l=0$ полюс 0 превращается в 1. Полученная тройка $(1,1,1)$ соответствует позиции 1.

В обычном порядке функций построенная модель:

$$
1:\text{ЧЭ},\quad2:\text{БИ},\quad3:\text{ЧЛ},\quad4:\text{БС},
\quad5:\text{БЛ},\quad6:\text{ЧС},\quad7:\text{БЭ},\quad8:\text{ЧИ}.
$$
