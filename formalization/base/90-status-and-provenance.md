# Служебные сведения: источники, границы результатов и проверки

## Разделение документов

[Главы 1](01-hadamard-and-correspondence.md) и [2](02-generations-and-invariant-formulas.md) содержат последовательное изложение конструкции. [Техническое приложение](01a-hadamard-technical.md) содержит развёрнутые доказательства, перевод знаков и двоичные индексы. [Индекс](00-index.md) содержит порядок чтения и дальнейшей работы. Настоящий документ собирает сведения о происхождении, области проверок и состоянии разработки.

Основной текст предназначен прежде всего для исследователей, изучающих способ формализации. Программная реализация служит проверке точных утверждений; разработка самостоятельного демонстрационного экспоната относится к последующему этапу.

## Исходные правила и математическое изложение

Именование строк и столбцов, соответствие Чурюмова и опорная модель ИЛЭ берутся из таблиц проекта. Поколения и структурные схемы признаков берутся из исходных текстов. Короткие имена `vert`, `nal`, `tal`, `crat` и формула существования $t(I)=F$ согласованы с автором.

Развёрнутая логическая запись условий, доказательства H-01 и H-02, перевод $\sigma$ и двоичные записи индексов составляют математическое изложение этих данных. Конкретная поточечная запись X-01 предложена ассистентом для авторского принципа раздельного XNOR аспектных и функциональных составляющих. Общая операция для всех структурных классов пока не определена.

## Границы результатов

- Ортогональность и замкнутость доказаны для всех матриц Сильвестра.
- Имена объектов и их порядок являются исходными правилами выбранной реализации. Математические свойства матрицы не определяют соционические имена.
- Таблица главы 1 сопоставляет шестнадцать заданных типов, отношения относительно ИЛЭ, коды и модели. Модели здесь являются исходными данными, а не результатом уже завершённого конструктора.
- Все полные условия главы 2 сопоставлены с обоими полюсами соответствующих столбцов на этих шестнадцати моделях. Для каждого кода вся система условий одновременно выполнена ровно одной моделью из таблицы.
- Единственность среди всех биекций $I\to F$ требует отдельного доказательства построения. Прежний сессионный перебор не заменяет изложение и долговечную реализацию этой теоремы.
- Конъюнкция объединяет условия и выделяет их общий класс. Для двух независимых дихотомий четыре сочетания полюсов дают тетрахотомию. Вывод новой структурной формулы по XNOR её составляющих является отдельным видом комбинирования; X-01 устанавливает конкретный поточечный случай, а не общую операцию для всех поколений.
- Группа кодов с XNOR и группа перестановок с композицией имеют разные законы: первая абелева и изоморфна $C_2^4$, вторая некоммутативна и изоморфна $8T9\cong D_8\times C_2$. Их табличное соответствие не является групповым изоморфизмом.

## Воспроизведение

Из корня репозитория:

```bash
python -m unittest discover -s tests -p "test_base_*.py" -v
python -m unittest discover -s formalization/equivariant-8T9 -v
```

| Файл | Область проверки |
|---|---|
| `tests/test_base_hadamard.py` | Матрицы порядков 8 и 16, исходные таблицы, XNOR, опорное соответствие и поточечные комбинирования |
| `tests/test_base_generations.py` | Буквальные таблицы главы 2, все пятнадцать признаков с обоими полюсами, диады и полутакты |
| `tests/test_base_explanations.py` | Буквальная таблица типов/отношений/кодов/моделей, полный образ носителя, короткие имена, два групповых закона, совместное применение условий и примеры приложения |
| `formalization/equivariant-8T9/test_equivariant.py` | Закон композиции, действия на столбцах, дефекты, сопряжение и отдельный пример беспечности |

## Метакомментарии, оставленные для редакторского решения

В основных главах удалены пометки о прежней записи $M_t(i)$, персональном предложении формулы и ходе разработки. Происхождение и ограничения результата сохранены выше. В отложенной исследовательской заметке остаются следующие формулировки:

1. **Начало главы 3:** «Статус: отложенная исследовательская заметка. Здесь предложена ассистентом запись авторского принципа для поточечных формул».
2. **§3.2:** «Это точная запись предложенного поточечного случая авторского принципа. Она не использует композицию перестановок».
3. **§3.6:** «Авторская нотация этого механизма пока не существовала; следующая конструкция должна быть явно обозначена как предложенная формализация».
4. **Раздел «Происхождение и проверки»:** «Поточечная конструкция и доказательство X-01 — предложенная ассистентом формальная запись».

Эти персональные и редакционные пояснения можно убрать из заметки, сохранив сведения о происхождении в настоящем документе. Содержательные границы X-01 — общая область действия, односторонность вывода и отсутствие установленного правила для разных областей — должны оставаться при самом утверждении.
