# Инварианты восьми тетрахотомий с +/− и ?/!

32 тетрады; по два эквивалентных одиночных условия для каждой. Расчёт выполнен по предоставленной таблице 16 моделей А и признаков Рейнина. Номера тетрахотомий соответствуют файлу «4-svezhak.md».

## Обозначения и смысл формул

Пусть $A$ — множество восьми аспектов, $F=\{1,\ldots,8\}$ — множество функций, $\psi_T:A\to F$ — модель типа $T$.

Используется классическая нумерация функций: 1 — программная, 2 — творческая, 3 — ролевая, 4 — болевая, 5 — суггестивная, 6 — активационная, 7 — ограничительная, 8 — фоновая.

В каждой строке ниже указана тетрада $Q$ и два условия вида

$$
\psi_T^{-1}(K)\subseteq e_i^+,\qquad |K|=2,\quad |e_i^+|=4.
$$

Условие означает: оба аспекта, занимающие функции из пары $K$, принадлежат указанной четвёрке $e_i^+$. Эквивалентная запись: $K\subseteq\psi_T(e_i^+)$.

Каждая из двух формул самостоятельно характеризует тетраду среди 16 заданных моделей:

$$
T\in Q
\quad\Longleftrightarrow\quad
\psi_T^{-1}(K_1)\subseteq e_{i_1}^+
\quad\Longleftrightarrow\quad
\psi_T^{-1}(K_2)\subseteq e_{i_2}^+.
$$

Объединять два условия конъюнкцией для выделения тетрады не требуется. В записи $\psi_T^{-1}(K)$ выбираются аспекты, занимающие функции из пары $K$.

В равенствах признаков $\odot$ обозначает XNOR: положительный полюс кодируется 1, отрицательный — 0. Три значения в столбце «Полюса» приведены в порядке признаков, указанном перед соответствующей таблицей.

## Общая конструкция и проверка

Для каждой тетрахотомии и каждого из двух допустимых выборов $e_i^+$ четыре функциональные пары $K$ образуют разбиение множества $F$. У каждого типа ровно одна из этих пар целиком содержится в $\psi_T(e_i^+)$. Выбор пары задаёт четырёхзначный инвариант тетрахотомии.

Для каждой тетрады $Q$ и каждого допустимого $e_i^+$ множество образов

$$
\mathcal U_{Q,i}=\{\psi_T(e_i^+):T\in Q\}
$$

состоит из двух различных четвёрок функций. Их пересечение равно функциональной паре из формулы:

$$
K=\bigcap_{T\in Q}\psi_T(e_i^+),\qquad |K|=2.
$$

Условие $K\subseteq\psi_T(e_i^+)$ затем проверено на всех 16 моделях; оно выбирает точно $Q$.

Проверены:

- восемь равенств признаков на всех 16 типах;
- разбиение 16 типов на четыре тетрады в каждом из восьми случаев;
- все 28 функциональных пар для каждой из четырёх четвёрок $e_4^+,\ldots,e_7^+$: для каждой тетрады получено ровно два решения $(i,K)$;
- все 64 итоговые формулы на всех 16 моделях — 1024 значения истинности; каждое условие истинно на своей тетраде и ложно вне неё;
- для каждого из 16 вариантов описания целой тетрахотомии — разбиение функций на четыре пары и единственность целиком содержащейся пары для каждого типа.

Дополнительно перебраны все 70 четвёрок аспектов для каждой из 32 тетрад. Ни в одной из них нет четвёрки аспектов с одинаковым четырёхэлементным образом у всех четырёх типов. Это ограничение относится к фиксированному соответствию $4\to4$ внутри тетрады; приведённые формулы используют обратное включение $2\to4$.
