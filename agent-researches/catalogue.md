# Каталог дихотомических и тетрахотомических инвариантов

Для каждой строки $Q$ приведён один точный представитель: условие истинно ровно на указанных типах среди 16 моделей А. Полный набор вариантов и все общие включения восстанавливаются из `catalogue.json`; схему данных описывает `README.md`.

$\psi_T$ отображает аспекты в классические номера функций. Равенство множеств используется при одинаковых мощностях; $\subseteq$ означает включение. Введены

$$
b(T)=(\psi_T(\text{ЧИ}),\psi_T(\text{БЛ})),\qquad
\rho=(1\,2\,3\,4)(5\,6\,7\,8).
$$

Для любой строки $T\in Q\iff b(T)\in M_Q$. Эта дополнительная запись единообразна для всех 170 классов. Пары в $M_Q$ упорядочены: первое число — позиция ЧИ, второе — позиция БЛ.

Само $b(T)$ кодирует отдельный тип. Полный инвариант заданной тетрахотомии возвращает номер того из четырёх множеств $M_Q$, которому принадлежит $b(T)$.

Число «включений» — минимальное число условий $\psi_T(B)\subseteq C$ в точном описании; «невозможно» означает, что даже все общие включения не выделяют класс. Числа вариантов не отождествляются с числом независимых инвариантов.
