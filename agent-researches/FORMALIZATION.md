# Первый формальный слой: эквивариантная алгебра признаков на 8T9

**Статус:** конструкция и доказательство формул в выбранных координатах; конечные равенства проверены на таблице из пакета `2026-09-29-fraktal-H16-8T9-vychisleniya.zip`. Конкретные 2→4 и порядкозависимые формулы АРП ещё не включены как доказанные образующие алгебры.

## 1. Два закона на шестнадцати метках

Положим `V = F₂⁴` и зададим координаты `x=(e,d,r,z)` битами отрицательных полюсов: интроверсия, аристократия, рациональность, предусмотрительность. `H₁₆` имеет столбцы `h_λ(x)=(-1)^<λ,x>`, `λ∈V*`, для сложения `⊕` по координатам. Это характеры `(V,⊕)`; первый столбец постоянен.

Дополнительные данные — шестнадцать биекций модели А `m_t:F→A`, базовая модель `m_ИЛЭ` и сопоставление строкам кодов `x(t)`. Они задают перестановки `π_t=m_t⁻¹∘m_ИЛЭ ∈ S(F)`. Выбранная таблица имеет замкнутый набор `G={π_t}`; композиция `pq=p∘q`. Перенос группового закона с `G` на `V` имеет вид

```
(e,d,r,z) ⋆ (e',d',r',z') = (e+e', d+d', r+r', z+z'+d r')    (mod 2).
```

Поправка `β(x,y)=d_x r_y` является нормированным 2-кокциклом относительно сложения первых трёх координат: равенство `β(x,y)+β(x+y,w)=β(y,w)+β(x,y+w)` следует из билинейности. Поэтому `⋆` ассоциативна. Отображение `(d,r,z)` в верхнетреугольную матрицу с наддиагональными элементами `d,r,z` даёт `G≅UT₃(F₂)×C₂≅D₈×C₂` (здесь `D₈` порядка 8; иной индекс — `D₄`). Для `H₁₆` от `H₁` есть четыре удвоения; от `H₂` до `H₁₆` — три. Тензорная рекурсия сама не определяет ни `m_t`, ни `⋆`: необходима выбранная модель-А-реализация.

## 2. Алгебра функций и действие группы

Положим `𝒜=Fun(G,ℝ)` с поточечным умножением. Шестнадцать столбцов Адамара образуют базис этой алгебры, и `h_λ h_μ=h_{λ+μ}`. Переносы задают коммутирующие левое и правое действия на функциях:

```
L_g f(x)=f(g⁻¹⋆x),       R_g f(x)=f(x⋆g⁻¹).
```

Для `λ=(a,b,c,q)` и `g=(e,d,r,z)`, если `g⁻¹=(e,d,r,z+dr)`, то

```
L_g h_(a,b,c,q) = h_λ(g⁻¹) h_(a,b,c+qd,q),
R_g h_(a,b,c,q) = h_λ(g⁻¹) h_(a,b+qr,c,q).
```

Следовательно, базис `H₁₆` **эквивариантен**: переносы не обязаны сохранять отдельный столбец, но переставляют столбцы с возможной сменой знака. При `q=0` получаются восемь одномерных характеров `G` (семь непостоянных и единица). При `q=1` восемь признаков третьего поколения имеют одинаковый дефект мультипликативности:

```
h_λ(x⋆y) = h_λ(x) h_λ(y) (-1)^(d_x r_y).
```

Поэтому признак третьего поколения остаётся двоичной функцией на типах, но его положительный полюс вообще не является ядром гомоморфизма `G→C₂`. Его геометрическое выражение требует отдельной формулы инцидентности для размещения аспектов.

## 3. Инварианты при сопряжении

При `C_g f(x)=f(g⁻¹⋆x⋆g)` получаем

```
C_g h_(a,b,c,q) = h_(a,b+qr,c+qd,q).
```

Восемь столбцов с `q=0` фиксированы, а восемь с `q=1` распадаются на две орбиты по четыре (различаются битом `a`). Суммы столбцов внутри этих орбит — инварианты сопряжения. Значит, подалгебра `𝒜^G` классовых функций имеет размерность 10: восемь одиночных столбцов и две независимые орбитальные суммы. Число 10 также равно числу классов сопряжённости этой конечной группы. Это **другая** алгебра, чем полная `𝒜`: если преждевременно оставить только классовые функции, отдельные признаки третьего поколения потеряются.

Поточечная `𝒜` коммутативна, тогда как свёртка на том же пространстве функций, эквивалентная групповой алгебре `ℝ[G]`, некоммутативна. Нельзя называть эти два умножения одним действием «алгебры инвариантов»; полезно хранить оба, с явными операциями.

## 4. Геометрические образующие для формул АРП

Для модели `ψ:A→F` определим семейство функций инцидентности

```
I_(D,B)(ψ) = 1[ψ(D) ⊆ B],       D⊆A, B⊆F.
```

Это естественный язык 2→4 для третьего поколения. При `u∈Sym(A)` и `v∈Sym(F)` верно строгое тождество переноса

```
I_(uD,vB)(v∘ψ∘u⁻¹) = I_(D,B)(ψ).
```

Фиксированная пара `(D,B)` не обязана быть инвариантной: эквивариантно **семейство** таких предикатов вместе с действием на параметрах. Для признаков 1–2-го поколений аналогично берутся блочные условия 4→4; для четвёртого поколения — условия на упорядоченных парах или факторном цикле. В конечном наборе моделей каждый конкретный предикат должен быть проверен на всех шестнадцати `ψ_t` на эквивалентность нужному столбцу `H₁₆` (в обе стороны), с записью полюса и конвенций. Только после этой проверки он может считаться установленной модельно-А-реализацией признака.

В качестве первого законченного случая проверена формула третьего поколения «Беспечность» из `formuly-dihotomij-arp.md`, строки 239–253: `{ЧИ,БС}` попадает в `{1,4,5,8}`, `{ЧС,БИ}` — в `{2,3,6,7}`; противоположный полюс меняет блоки местами. Для всех 16 моделей условия совпали с обеими сторонами столбца «Беспечность» из `H₁₆`. Проверено также приведённое тождество эквивариантности для этих множеств при одновременном переносе области и образа. Это один верифицированный пример 2→4, а не проверка остальных семи признаков третьего поколения.
