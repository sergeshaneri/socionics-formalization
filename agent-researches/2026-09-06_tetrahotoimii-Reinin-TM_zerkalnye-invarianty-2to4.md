# 2026-09-06 — Тетрахотомии Рейнина и Тенсера—Минаева: зеркальные инварианты 2→4

## Постановка задачи

Проверить восемь тетрахотомий Рейнина, связанных с признаками **позитивизм/негативизм (+/−)** и **квестимность/деклатимность (?/!)**, для которых были найдены новые инварианты вида

\[
\psi_T^{-1}(K)\subseteq e_i^\pm,
\qquad |K|=2,\quad |e_i^\pm|=4,
\]

то есть две функции отображаются в четвёрку аспектов.

Задачи исследования:

1. проверить корректность этих инвариантов;
2. определить их связь с пространством Тенсера—Минаева;
3. найти соответствующие тетрахотомии в ТМ-пространстве;
4. проверить, существуют ли там зеркальные формулы вида «2 аспекта → несколько функций»;
5. проверить минимальный размер функционального множества в таких формулах.

---

## Используемые соглашения

Пусть

\[
A=\{\text{ЧИ, БС, ЧЭ, БЛ, ЧЛ, БЭ, ЧС, БИ}\}
\]

— множество аспектов,

\[
F=\{1,\ldots,8\}
\]

— множество функций модели А,

\[
\psi_T:A\to F
\]

— перестановка модели А типа \(T\).

Используется классическая нумерация функций:

1 — программная,  
2 — творческая,  
3 — ролевая,  
4 — болевая,  
5 — суггестивная,  
6 — активационная,  
7 — ограничительная,  
8 — фоновая.

Для пространства Тенсера—Минаева используется ранее зафиксированное соответствие базисов:

\[
(\mathrm{Верт},\mathrm{Наль},\mathrm{Дм/Ар},\mathrm{Вес/Сер})
\longleftrightarrow
(\mathrm{Верт},\mathrm{Наль},\mathrm{Дм/Ар},1\alpha/1\gamma).
\]

# 1. Проверка восьми рейнинских тетрахотомий

Рассмотрены тетрахотомии №:

\[
9,\ 11,\ 15,\ 16,\ 24,\ 25,\ 31,\ 35.
\]

Для каждой из 32 тетрад были найдены инварианты вида

\[
\psi_T^{-1}(K)\subseteq e_i^\pm,
\]

где \(K\subset F\) — пара функций, а \(e_i^\pm\subset A\) — один из полюсов нетемпераментных элементных дихотомий Гуленко—Ньюмана.

Используются четыре элементные дихотомии:

\[
e_4,\ e_5,\ e_6,\ e_7.
\]

Их положительные полюса:

\[
e_4^+=\{\text{ЧИ, ЧЭ, БЛ, БИ}\},
\]

\[
e_5^+=\{\text{ЧИ, ЧЛ, БЭ, БИ}\},
\]

\[
e_6^+=\{\text{ЧИ, БС, БЛ, ЧЛ}\},
\]

\[
e_7^+=\{\text{ЧИ, БС, ЧЭ, БЭ}\}.
\]

При учёте только положительных полюсов каждая тетрада имеет по два эквивалентных одиночных условия.

Если добавить отрицательные полюса \(e_i^-\), каждая тетрада имеет ровно **четыре** эквивалентных одиночных условия.

Пример для тетрады №9

\[
\{\mathrm{ИЛЭ,ЛСИ,ЛИЭ,СЛИ}\}
\]

получаем:

\[
\psi^{-1}(18)\subseteq e_6^+,
\]

\[
\psi^{-1}(27)\subseteq e_7^-,
\]

\[
\psi^{-1}(36)\subseteq e_6^-,
\]

\[
\psi^{-1}(45)\subseteq e_7^+.
\]

То есть каждая тетрада задаётся четырёхцикленным набором эквивалентных условий.

# 2. Структура найденных рейнинских формул

Общая форма:

\[
\boxed{2F\to4A}
\]

или более строго:

\[
\boxed{
\psi_T^{-1}(K)\subseteq E,
\qquad |K|=2,\ |E|=4.
}
\]

Эти формулы существенно отличаются от обычных кольцезависимых формул АРП:

- \(4A\to4F\),
- \(2A\to4F\).

Здесь отображение читается в обратную сторону:

\[
2\ \text{функции}
\longrightarrow
4\ \text{аспекта}.
\]

Причём четвёрки аспектов принадлежат именно альтернативной элементной системе Гуленко—Ньюмана.

Это связывает восемь рассматриваемых рейнинских тетрахотомий непосредственно с GN/TM-структурой.

# 4. Зеркальные формулы в ТМ-пространстве

Для каждой из 32 ТМ-тетрад найдено ровно четыре условия вида

\[
\psi_T(P)\subseteq H,
\qquad |P|=2,\quad |H|=4.
\]

То есть:

\[
\boxed{2A\to4F}
\]

Это зеркальная конструкция по отношению к рейнинским формулам:

\[
\boxed{
\text{Рейнин: } 2F\to4A
}
\]

\[
\boxed{
\text{ТМ: } 2A\to4F
}
\]

Пример.

Для соответствующей ТМ-тетрады №9 одна из тетрад:

\[
\{\mathrm{ИЛЭ,ЛСИ,ИЭИ,ЛИЭ}\}
\]

характеризуется условием

\[
\boxed{
\psi_T(\{\mathrm{ЧИ},\mathrm{ЧЛ}\})
\subseteq
\{1,4,7,8\}.
}
\]

Для неё существуют ещё три эквивалентных условия с другими парами аспектов.

# 7. Проверка формул 2 аспекта → 3 функции

Был отдельно проверен класс условий:

\[
\psi_T(P)\subseteq H,
\qquad |P|=2,\quad |H|=3.
\]

Для каждой ТМ-тетрады перебраны все варианты

\[
\binom82\binom83
=
28\cdot56
=
1568.
\]

Для 32 тетрад:

\[
32\cdot1568=50176
\]

проверок.

Результат:

\[
\boxed{
\text{формул }2A\to3F\text{, выделяющих тетраду, не найдено.}
}
\]

Также:

\[
2A\to2F:\quad 0,
\]

\[
2A\to3F:\quad 0,
\]

\[
2A\to4F:\quad
\boxed{4\text{ формулы на каждую тетраду}}.
\]

На рейнинской стороне зеркально:

\[
2F\to2A:\quad0,
\]

\[
2F\to3A:\quad0,
\]

\[
2F\to4A:\quad
\boxed{4\text{ формулы на каждую тетраду}}.
\]

Это указывает, что размер 4 является минимальным для данного класса одиночных включений.

# 8. Симметрия двух пространств

Полученная структура:

\[
\boxed{
\begin{array}{ccc}
\text{Reinin-тетрада}
&
2F\subset4A_{\mathrm{GN}}
\\[4pt]
\updownarrow
&
\updownarrow
\\[4pt]
\text{TM-тетрада}
&
2A\subset4F_{\mathrm{alt}}
\end{array}
}
\]

То есть:

- рейнинская тетрада выбирается парой функций внутри четверки аспектов альтернативной элементной системы;
- соответствующая ТМ-тетрада выбирается парой аспектов внутри четверки функций альтернативной позиционной системы.

Это не просто сходство записи. Обе стороны используют вторые адамаровы дополнения к общей темпераментной тройке.

---

# 9. Почему выделяются именно +/− и ?/!

Восемь специальных тетрахотомий делятся на две группы:

## Через +/−

\[
9,\ 15,\ 24,\ 25
\]

## Через ?/!

\[
11,\ 16,\ 31,\ 35.
\]

Таким образом:

\[
8=4+4.
\]

Это согласуется с тем, что \(+/-\) и \(?/!\) входят в общий порядкозависимый слой и являются двумя различными направлениями внутри общей Fano-структуры признаков четвёртого поколения.

Рабочая гипотеза:

> специальная зеркальность \(2F\to4A\) / \(2A\to4F\) связана не со всеми тетрахотомиями, а с теми, в которых порядкозависимая часть взаимодействует с парой зеркально соответствующих Рейнин/TM-признаков.

Эта гипотеза требует полного перебора остальных 20 необщих соответствующих пар тетрахотомий.

# 10. Техническая поправка к файлу формул TM-признаков

При проверке формул Тенсера—Минаева обнаружено расхождение для двух признаков.

Для **2-detached / 2-involved** и **2-implicit / 2-explicit** запись через пары функций \(26\) и \(48\) не согласуется с таблицей 16 моделей А при классической нумерации.

Корректная пара функций:

\[
28,\ 46.
\]

Для 2-detached:

\[
\psi^{-1}(28)
\subseteq
\{\text{ЧИ,БИ,ЧЛ,БЛ}\},
\]

\[
\psi^{-1}(46)
\subseteq
\{\text{ЧЭ,БЭ,ЧС,БС}\}.
\]

Для 2-explicit:

\[
\psi^{-1}(28)
\subseteq
\{\text{ЧЛ,БЛ,ЧС,БС}\},
\]

\[
\psi^{-1}(46)
\subseteq
\{\text{ЧИ,БИ,ЧЭ,БЭ}\}.
\]

Перед дальнейшей классификацией соответствующий исходный файл следует исправить.

# 11. Основной результат

Для восьми тетрахотомий Рейнина, содержащих \(+/-\) или \(?/!\), обнаружена точная зеркальная связь с соответствующими тетрахотомиями Тенсера—Минаева:

\[
\boxed{
\mathrm{Reinin}: 2F\to4A
}
\]

\[
\boxed{
\mathrm{TM}: 2A\to4F
}
\]

Обе конструкции:

1. используют пары из Fano-разбиений;
2. используют нетемпераментные альтернативные адамаровы дополнения;
3. имеют ровно по четыре эквивалентных одиночных формулы на тетраду;
4. не имеют аналогов с целевым множеством размера 2 или 3.

Минимальный размер целевого множества:

\[
\boxed{4}.
\]
