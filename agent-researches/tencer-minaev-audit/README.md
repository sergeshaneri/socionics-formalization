# Инварианты Тенсера—Минаева

Дата: 2026-09-07. Исследование 15 дихотомий, 35 тетрахотомий и 15 октохотомий.

Основной документ — 2026-09-07-tencer-minaev-invariants.md; PDF содержит ту же редакцию. Все 290 классов имеют точные формулы, проверенные на 16 моделях.

## Воспроизведение

Python 3.10 или новее, стандартная библиотека:

    python3 audit.py
    python3 build_report.py
    python3 verify_report.py

Последняя команда независимо интерпретирует буквальные LaTeX-формулы, выведенные в документ, и проверяет 4640 значений истинности. Также проверяет все 65 полных инвариантов разбиений.

Для PDF нужны Pandoc, XeLaTeX и шрифты DejaVu:

    python3 build_pdf.py

Расчёт автономен: audit.py читает только inputs.json и не обращается к другим каталогам или сети.

## Файлы

- inputs.json: таблица моделей, исходные признаки Рейнина, нумерация разбиений, исходные 64 формулы, контрольные результаты предыдущего исследования.
- audit.py: прямой исчерпывающий расчёт на обратных отображениях моделей.
- catalogue.json: все результаты и параметры формул.
- statistics.json: сводная статистика.
- build_report.py: генератор Markdown.
- emitted-formulas.json: 290 основных формул в точной строковой записи LaTeX.
- verify_report.py: независимая проверка этих строк и полных инвариантов.
- report-verification.json: результат последней проверки документа.
- build_pdf.py, pdf-header.tex, pdf-layout.lua: воспроизводимая вёрстка PDF.
- sources/: исходные файлы проекта без изменений; source-manifest.json связывает локальные имена с именами загруженных документов.
- package-manifest.json: размеры и SHA-256 файлов комплекта, кроме самого манифеста.

## Нумерация и полярность

Функции имеют классические номера 1..8: программная, творческая, ролевая, болевая, суггестивная, активационная, ограничительная, фоновая. Порядок строк «Функциона» не меняет номера.

Положительный полюс кодируется 1, отрицательный — 0; умножение признаков соответствует XNOR. Обычные координаты над F₂ используют 1−признак. Базис индексов [1,14,4,2] соответствует (экстраверсия, иррациональность, демократия, 1-дельта) для ТМ.

D01+ и D01− — два полюса m₁; T09.1 — первая тетрада зеркальной тетрахотомии №9; O07.3 — третья пара зеркальной октохотомии №7. Нумерация зеркальна предыдущему каталогу Рейнина, составы пересчитаны по ТМ.

Аспекты в битовых масках: [ЧИ, БС, ЧЭ, БЛ, ЧЛ, БЭ, ЧС, БИ]. Бит i равен 1, когда элемент с индексом i включён. Для функций бит f−1 соответствует номеру f. Для типов порядок задан type_order.

## Схема catalogue.json

- input: полный использованный вход.
- theta: образ восьми аспектов при ИЛЭ, в классических номерах функций.
- iota: перестановка индексов типов, соответствующая обращению нормированных моделей.
- tm_traits: все признаки ТМ, включая существование.
- reinin_codes, tm_codes: обычные четырёхбитные координаты; tm_codes = reinin_codes с заменой c на c+nd.
- trait_vectors: коэффициенты линейных форм признаков в координатах ТМ.
- group_elements_on_functions: h_T = theta ◦ phi_T, перестановки функций с индексами 0..7.
- group_multiplication, group_inverses: точные таблицы этой группы.
- operational_definitions: положительные полюса восьми новых признаков через одну функцию и четвёрку аспектов.
- families: 65 полных разбиений; class_ids, независимый basis, все общие traits, тип полного инварианта и параметры.
- classes: 290 классов; конкретные составы, значения признаков, битовая маска, формулы, замыкания и альтернативы.
- inclusion_predicates: ключ — маска множества решений; значение — все пары [K,S] условия phi_T(K) ⊆ S.
- intersection_observations: строки [K,S,[[r,truth_mask],...]] для всех 65536 наблюдений мощности пересечения.
- exact_intersection_predicates: все [K,S,r] с множеством решений, равным одному из изучаемых классов.
- exact_spectrum_predicates: все [K,S,[r₁,...]] с точным множеством решений.
- partition_transport_predicates: ключ — маска решений; строки [source_blocks,target_blocks] описывают все непустые транспортеры разбиений. Исходные блоки — маски функций, целевые — маски аспектов.
- source_audit: исходные обратные формулы, их истинностные маски и зеркальные исправления.

Для каждого класса:

- inclusion_witness — точное включение либо минимальная конъюнкция. Пустой список означает невозможность в этом языке.
- unary_support[f−1] — все аспекты функции f, встречающиеся в классе.
- inclusion_closure — пересечение всех общих включений.
- intersection_witness, spectrum_witness, partition_witness — выбранные точные представители, если существуют.
- fixed_subset_exact_maps — все собственные непустые равенства phi_T(K)=S, выделяющие класс.
- image_family_constraints — [K,allowed_images,truth_mask] для всех собственных непустых K; допускается несколько альтернативных образов.
- partition_closure, balanced_partition_closure — пересечения всех общих переносов произвольных или равновеликих разбиений.
- partition_conjunction_witness, balanced_partition_witness — минимальные точные конъюнкции при их существовании.
- transport_hull — наименьший смежный класс группы нормированных обратных моделей, содержащий рассматриваемый класс типов.
- transport_exact — равенство этого замыкания классу.
- transport_orbit_source — пары классических функций 1..8.
- transport_orbit_target — пары индексов аспектов 0..7.
- canonical_ordered_pairs — допустимые пары индексов аспектов на функциях 1 и 2.
- fourier_numerators — коэффициенты Фурье индикатора класса, умноженные на 16.
- indicator_degree — минимальная степень индикатора в матричных координатах модели над R; это не степень по бинарным признакам.
- complete_invariant_value — значение полного инварианта семейства на данном классе.

## Проверки и границы полноты

Исчерпывающий перебор: 65536 пар подмножеств, 4140 разбиений восьми точек, 35 подгрупп группы моделей, 179 смежных классов. Все вычисления точные.

Контрольные характеристики Рейнина из inputs.json служат только проверками. Истинностные множества ТМ вычисляются непосредственно по моделям, а не копируются из прежнего каталога.

Все синтаксические варианты в JSON — параметрические записи. Дополнительные полюса и обращения направлений часто задают один и тот же предикат. Число таких записей не интерпретируется как число независимых инвариантов.

Исследование устанавливает полноту для указанных конечных языков и критерий произвольного точного переноса фиксированной структуры. Для формул с произвольной дизъюнкцией допускается универсальный код; отдельная минимизация всех логических выражений не проводилась.
