## 3. Тетрада как множество перестановок
Тетраде соответствует B = {gₜ : t принадлежит тетраде} ⊂ G. Множество B может не содержать единицу. Относительно b ∈ B получаем S = Bb⁻¹, содержащее единицу.

Порожденная группа внутренних переходов: H(B) = ⟨uv⁻¹ : u,v ∈ B⟩. Для любого b ∈ B она равна ⟨Bb⁻¹⟩. Множество всех внутренних отношений BB⁻¹, четырёхэлементное S и группа H(B) хранятся отдельно.

L(B) = {a ∈ G : aB = B}; R(B) = {a ∈ G : Ba = B}. Это стабилизаторы самой четвёрки в левом и правом регулярных действиях. L(B) ⊆ H(B). Если |L(B)| = 4, то B = L(B)b — правый смежный класс и S является подгруппой. Если |L(B)| = 2, исходная четвёрка сохраняется меньшей группой, чем её замыкание.

Для 60 тетрад |L(B)| = |R(B)| = 4; для 80 тетрад оба порядка равны 2. Во втором случае B является объединением двух орбит L(B), каждая размера 2. Эти стабилизаторы не следует смешивать со стабилизаторами отдельных функций в действии H(B) на восьми точках.

Матрица отношений rᵢⱼ = gⱼgᵢ⁻¹ задаёт размеченный ориентированный полный граф четырёх типов. Она сохраняет совместимость переходов, которую теряет простой перечень отношений. Матрицы всех 140 графов включены в данные.

## 5. Десять классов с точностью до симметрий модели

Перебраны все 8! = 40320 перенумеровок. Получено |N| = 64, а число различных индуцированных автоморфизмов G равно 16. Вместе с левыми переносами они образуют группу из 256 перестановок множества моделей. Обе исследуемые семьи (140 тетрад и 35 разбиений) замкнуты относительно этой группы.

Эта эквивалентность также охватывает все независимые перенумерации исходных и конечных восьми координат, сохраняющие семейство моделей: uGv⁻¹ = G влечёт uv⁻¹ ∈ G и v ∈ N, откуда ugv⁻¹ = (uv⁻¹)(vgv⁻¹). Она сохраняет структуру всей реализации, но может менять соционические названия функций.

### Порядок совместного ограничения
Для набора аспектов I определим P_I(B) = {(ψₜ(a))_{a∈I} : t ∈ B}. Восстановление по ограничениям порядка k оставляет модели, чьи кортежи принадлежат P_I(B) для каждого I размера k. Это проверка совместных допустимых положений, без вероятностного предположения.

Для 116 тетрад достаточно k=1. Для оставшихся 24 минимально k=2; при k=1 остаётся 8 моделей. В каждом из этих 24 случаев найдена даже одна пара аспектов, множество допустимых упорядоченных положений которой выделяет тетраду.

Пример №2, тетрада ИЛЭ–ЭСЭ–ЛИЭ–СЭЭ: (ψ(ЧИ),ψ(БЛ)) ∈ {(1,2),(3,4),(6,5),(8,7)}. По отдельности ЧИ допускает {1,3,6,8}, а БЛ — {2,4,5,7}; совместный список запрещает лишние сочетания и сокращает восемь моделей до четырёх.

Матрица M_B(a,f) = число типов t ∈ B, у которых ψₜ(a)=f, сохранена для каждой тетрады. Для проверки k=1 используется её носитель M_B(a,f)>0. Частоты и совместные кортежи являются дополнительными объектами; классификация только по размерам носителей заведомо грубее полного паспорта.

## 7. Связь дихотомий с группой отношений

Проверено, что только семь неконстантных удовлетворяют χ(gh)=χ(g)χ(h). Это вертность, нальность, тальность, кратия, +/−, ?/! и процесс/результат.

## 8. Стабилизаторы, орбиты и инвариантные структуры
Для разбиения Π = {B₁,B₂,B₃,B₄} вычислены L(Π) = {g : {gBᵢ} = Π}, R(Π) аналогично и ядро действия L(Π) на блоках, равное пересечению L(Bᵢ). Для разбиения могут сохраняться все четыре блока как семейство при перестановке блоков между собой.

Если для тетрады фиксировано равенство ψₜ(A)=F, то H(B) сохраняет F как множество. Поэтому F является объединением её орбит. Если фиксируется перенос разбиения аспектов в разбиение функций, H(B) сохраняет соответствующее разбиение; группа может переставлять блоки. Для включения с |A|<|F| такого вывода о сохранении F уже нет.

Для всех 35 подгрупп перебраны все 4140 разбиений восьми функций. Сохранены все нетривиальные инвариантные разбиения, включая неравномощные для нетранзитивных действий. Термин «система импримитивности» применяется к соответствующим транзитивным действиям; для общего каталога используется «инвариантное разбиение». Также вычислены орбиты каждой подгруппы на 64 упорядоченных парах функций. Они описывают сохраняемые бинарные отношения.

Стандартное различение действий на точках, множествах, кортежах и семействах множеств соответствует операциям OnPoints, OnSets, OnTuples, OnSetsSets в GAP. Источник: https://gap-system.github.io/gap/doc/ref/chap43_mj.html . Числовые результаты отчёта получены автономным Python-перебором, без вызова GAP.
