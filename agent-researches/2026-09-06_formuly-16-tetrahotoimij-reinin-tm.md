# Формулы 16 тетрахотомий Рейнина и Тенсера—Минаева

**Дата исследования:** 6 сентября 2026  
**Тема:** конкретные одиночные инварианты для восьми рейнинских тетрахотомий, содержащих $+/−$ или $?/!$, и восьми соответствующих им тетрахотомий Тенсера—Минаева.

## 1. Нотация

Пусть $A$ — множество восьми информационных аспектов, $F=\{1,\ldots,8\}$ — множество функций модели A, а
$$
\psi_T:A\to F
$$
— биекция аспектов на функции для ТИМа $T$.

Для рейнинских тетрахотомий используются условия типа
$$
\psi_T^{-1}(K)\subseteq e_i^{\pm},\qquad |K|=2,\quad |e_i^{\pm}|=4,
$$
то есть **два фиксированных функциональных места заняты аспектами из одной фиксированной четверки**. Каждое такое условие самостоятельно выделяет одну тетраду из 16 ТИМов.

Для соответствующих TM-тетрахотомий используются зеркальные условия
$$
\psi_T(P)\subseteq c_i^{\pm},\qquad |P|=2,\quad |c_i^{\pm}|=4,
$$
то есть **два фиксированных аспекта находятся внутри одной фиксированной четверки функций**.

В каждой из 64 тетрад ниже приведены **все четыре** одиночных условия найденного типа. Каждое из четырех условий эквивалентно принадлежности данной тетраде среди 16 моделей A.

### 1.1. Четверки аспектов $e_i^{\pm}$

$$
\begin{aligned}
e_4^+&=\{\text{ЧИ},\text{ЧЭ},\text{БЛ},\text{БИ}\}, & e_4^-&=\{\text{БС},\text{ЧЛ},\text{БЭ},\text{ЧС}\},\\
e_5^+&=\{\text{ЧИ},\text{ЧЛ},\text{БЭ},\text{БИ}\}, & e_5^-&=\{\text{БС},\text{ЧЭ},\text{БЛ},\text{ЧС}\},\\
e_6^+&=\{\text{ЧИ},\text{БС},\text{БЛ},\text{ЧЛ}\}, & e_6^-&=\{\text{ЧЭ},\text{БЭ},\text{ЧС},\text{БИ}\},\\
e_7^+&=\{\text{ЧИ},\text{БС},\text{ЧЭ},\text{БЭ}\}, & e_7^-&=\{\text{БЛ},\text{ЧЛ},\text{ЧС},\text{БИ}\}.
\end{aligned}
$$

### 1.2. Четверки функций $c_i^{\pm}$

Это второе адамарово дополнение к общей темпераментной тройке функций:

## 3. Восемь соответствующих TM-тетрахотомий: $2A\to4F$

Полярности TM-признаков заданы через проверенные инварианты на той же таблице 16 моделей A. Для признаков **2-отвлечённые/2-вовлечённые** и **2-неявные/2-явные** используется исправленная функциональная пара $\{2,8\}/\{4,6\}$; запись $\{2,6\}/\{4,8\}$ из рабочего файла с формулами для этих двух признаков не согласуется с таблицей моделей A. Для признака в таблицах соответствия используется положительный полюс **2-явные**, то есть дополнение к множеству 2-неявных.

## 4. Структурная сводка

Для каждой из 32 рейнинских тетрад существует ровно четыре условия вида
$$
\psi_T^{-1}(K)\subseteq e_i^{\pm},\qquad |K|=2,\quad |e_i^{\pm}|=4.
$$

Для каждой из 32 соответствующих TM-тетрад существует ровно четыре зеркальных условия вида
$$
\psi_T(P)\subseteq c_i^{\pm},\qquad |P|=2,\quad |c_i^{\pm}|=4.
$$

Таким образом исследуемая пара пространств проявляет симметрию
$$
2F\longrightarrow4A \qquad\leftrightarrow\qquad 2A\longrightarrow4F.
$$

Перебор условий $2A\to2F$ и $2A\to3F$ для этих TM-тетрад не дал одиночных условий, выделяющих тетраду. Минимальный найденный размер функционального контейнера равен четырём. Для рейнинской стороны зеркально минимальный размер аспектного контейнера также равен четырём.
