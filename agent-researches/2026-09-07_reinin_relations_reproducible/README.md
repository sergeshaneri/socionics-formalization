# Воспроизводимое исследование: признаки Рейнина и отношения модели А

Дата: 2026-09-07.

Комплект содержит исходные файлы проекта без изменений, код и результаты исследования. Основной численный источник: `project_sources/03-markdown-.md`, соответствующий загруженному файлу `markdown таблицы.md`. Имена остальных исходников и их контрольные суммы находятся в `research_work/full_input_manifest.json`.

## Запуск

Требуется Python 3.10 или новее. Для математических вычислений достаточно стандартной библиотеки, доступ в интернет не нужен. Запускайте команды из корня распакованного комплекта:

```bash
python3 research_work/compute.py
python3 research_work/audit_sources.py
python3 research_work/catalogue.py
python3 research_work/verify.py
python3 research_work/export_tables.py
```

Скрипты перезаписывают вычисляемые JSON/CSV в `research_work`, сохраняя исходники в `project_sources` и `upload`. Очерёдность существенна: каталог использует завершённые результаты вычисления и аудита.

## Что проверено

- 16 биективных моделей А; полные таблицы признаков типов, аспектов и функций.
- Все 256 произведений перестановок и явный закон композиции.
- Все 4096 троек для ассоциативности и обоих брейс-тождеств.
- Все 512 троек фактора для центрального 2-коцикла.
- Все 65 линейных разбиений: 15 дихотомий, 35 тетрахотомий и 15 октохотомий.
- Все 290 итоговых формул блоков на всех 16 моделях, в том числе отсутствие лишних типов.
- Сопряжение всех 16 элементов с официальной каталожной группой 8T9.
- Явная группа из 32 общих автоморфизмов, критерии подгрупп и идеалов.
- Исправленные формулы Тенсера–Минаева и обе системы аффинных координат моделей А.

`research_work/verification_results.json` должен содержать `"status": "PASS"`.

## Файлы результатов

- `normalized_data.json`: нормализованные таблицы, коды, перестановки, таблица Кэли, подгруппы, автоморфизмы, матрицы Адамара и альтернативные координаты.
- `catalogue.json`: все разбиения и блоки, точные формулы, позиционные границы, замыкания и относительные операторы внутри каждого блока.
- `source_audit.json`: все 1720 проверенных вхождений формул P5/P6, множества истинности, контрпримеры, непрочитанные синтаксические конструкции.
- `verification_results.json`: результаты независимых конечных проверок и исправленные TM-наборы.
- `tables/*.csv`: 13 таблиц UTF-8 с BOM, включая полную таблицу Кэли, матрицу отношений, исходные таблицы, каталог, орбиты и ошибки источников.
- `trans8.grp`: использованная копия официального файла GAP TransGrp, девятый элемент. Git blob SHA: `a909796aa9e29d3658c86daec1f16cb552e7bb7f`.

Файлы `*.clean.txt` воспроизводят текст исходных Markdown-файлов с заменой строк встроенных изображений на маркер. Эти изображения не нужны для вычисления численных таблиц; оригиналы сохранены отдельно без изменений.

## Соглашения

Координаты типа: `(e,r,n,l)` = отрицательные биты экстраверсии, иррациональности, интуиции и логики. Числовой код: `e + 2*r + 4*n + 8*l`. Начало: ИЛЭ.

Строка таблицы модели А перечисляет аспекты по функциям 1–8. Перестановки в JSON имеют нумерацию точек 0–7; CSV и отчёт используют обычные номера функций 1–8. Для композиции `P_x P_y` первым действует правый множитель.

Относительный оператор от x к y: `P_y P_x^{-1}`. Матрица `relative_operators.csv` имеет исходные типы в строках и конечные типы в столбцах; клетки содержат числовой код оператора. Названия операторов в словаре нормированы относительно ИЛЭ.

T01–T35 сохраняют номера тетрахотомий из `4-svezhak.md`; O01–O15 равны кодам направлений, а D01–D15 маскам признаков. Это не номера разделов незавершённого исходного файла октохотомий.

Минимальность формул относится к конечному языку включений, неупорядоченных парных транспортеров и двух макроаспектных циклов. Цена лексикографическая: число непозиционных предикатов, число указанных аспектов и функций, число конъюнктов. Абсолютная минимальность во всех логических языках не утверждается.

## Контроль целостности

`SHA256SUMS.json` в корне содержит хеши всех файлов комплекта, кроме самого этого манифеста. Хеши входных файлов сверяются с `full_input_manifest.json`. Успешная распаковка и проверка CRC всех элементов ZIP были выполнены при подготовке комплекта.

Для повторной сборки PDF дополнительно нужны Pandoc и XeLaTeX с шрифтами DejaVu Serif, DejaVu Sans, DejaVu Sans Mono и Latin Modern Math. Главный отчёт предоставлен в Markdown; материалы математического расчёта не зависят от наличия этих программ.
