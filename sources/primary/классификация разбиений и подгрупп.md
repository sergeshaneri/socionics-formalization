# Классификация разбиений и подгрупп

## Дихотомии

| Дихотомия         | Группа | Поколение | Действие    |
| ----------------- | ------ | --------- | ----------- |
| Вертность         | D8     | 1         | Интранзитив |
| Нальность         | E8     | 2         | Интранзитив |
| Тальность         | D8     | 2         | Интранзитив |
| Кратия (демо/ари) | Е8     | 4         | Транзитив   |
| ?/!               | D8     | 4         | Транзитив   |
| +/-               | D8     | 4         | Транзитив   |
| Пц/Рз             | С4xC2  | 4         | Транзитив   |

Обозначения в этом разделе сохранены в написании запроса: `E8` для нальности, `Е8` для кратии и `С4xC2` для Пц/Рз.

## Тетрахотомии по подгруппам отношений внутри четвёрок
